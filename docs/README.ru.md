# aimarket-mcp — MCP-сервер экономики агентов

> 🌐 [English](../README.md) · **Русский** · [Español](README.es.md) · [Français](README.fr.md) · [中文](README.zh.md) · [Глоссарий](https://github.com/alexar76/aicom/blob/main/docs/localization-glossary.md)

**aimarket-mcp** даёт инструментам Cursor / Claude доступ к живому Hub: поиск capability и **invoke** с подписанной **квитанцией**. Хостируемый endpoint: `https://modelmarket.dev/mcp`.

## Live

- [modelmarket.dev/mcp](https://modelmarket.dev/mcp)
- [Glama](https://glama.ai/mcp/servers/alexar76/aimarket-mcp)

```bash
cd aimarket-mcp
# затем — команды из English README → Quick start
```
